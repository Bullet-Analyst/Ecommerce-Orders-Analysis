🛒 E-commerce Sales & Logistics Data Analysis - Power BI

📌 Project Overview
This end-to-end Power BI project analyzes the sales, customer behavior, product performance, and logistics of an E-commerce platform. The interactive dashboard features a custom navigation menu and multiple report pages to help stakeholders track KPIs, identify profitable segments, and optimize delivery systems.

📊 Interactive Dashboards & Key Insights

1. Sales Performance Overview
This main page tracks the top-level KPIs such as Total Revenue, Profit, Total Orders, and Profit Margin. 
Key Visuals:Revenue vs Profit Monthly Trend line and Category-wise Sales Distribution.
![Sales Overview](Sales%20Overview.png)

2. Customer Insight Dashboard
Focuses on user demographics and retention metrics.
Key Insights: Tracks Total Customers, Average Order Value (AOV), and Returning Customers. Includes a geographic map for Customer Distribution by Region and a Top Client Leaderboard.
![Customer Insight](Customer%20Insight%20Dashboard.png)

3. Product Performance Dashboard
Analyzes inventory and product-level profitability.
Key Insights: Compares Revenue vs Profit by Sub-category (Laptops, Mobiles, Headphones) using a customized bar chart and highlights brand profitability details.
![Product Performance](Product%20Performence%20Dashboard.png)

4. Orders & Logistics Performance
Tracks the operational side of the e-commerce business.
Key Insights: Monitors Return Rates (11.64%), Average Delivery Time, and Total Shipping Costs. Includes payment method breakdown (PayPal, Credit Card, Wallet, COD) and Return Rate by Product Category.
![Orders & Logistics](Orders%20&%20Logistics%20Performance.png)

5. Executive Report & Exports
A detailed decomposition of the data for deep-dive analysis.
Key Visuals: A Decomposition Tree breaking down Total Revenue by Customer Type, Product Category, and Warehouse Region.
![Executive Report](Executive%20Report%20&%20Exports.png)

🛠️ Tools & Techniques Used
Power BI: Data cleaning, Data Modeling, DAX measures, and interactive data visualization.
UI/UX Design: Custom page navigation with bookmarks and customized button states for a seamless app-like experience.
Data Analytics: Time intelligence functions, Profit Margin calculations, and performance tracking against goals.
